-----> Generating GH token

Click your profile picture (top-right corner)
Click Settings
Scroll all the way down the left sidebar - Developer settings is the last item, below all the account stuff
Then: Personal access tokens -> Tokens (classic) -> Generate new token

Direct link (should work if you're logged in):
     https://github.com/settings/tokensa

Yes, fine-grained tokens work fine for git push over HTTPS.

Quick setup:

Give it a name and expiration
Under Repository access, select "Only select repositories" and pick your repo (or "All repositories" if simpler)
Under Permissions -> Repository permissions, select Contents and then set to Read and write
Generate, then copy the token
Paste it as the password when git prompts you.



One catch: if your repo is under an organization, the org may need to
approve fine-grained tokens before they work - classic tokens don't have
this restriction. If you hit a permission error after setup, that's likely
why, and classic would be the simpler fallback.
